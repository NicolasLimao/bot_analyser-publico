# Fluxo de trabalho

- Preferência do responsável: após concluir as alterações e executar as verificações adequadas, criar um commit e fazer push para `main`, sem pedir nova confirmação.
- Incluir no commit somente as alterações da tarefa; preservar mudanças não relacionadas que já estejam no workspace.
- Não usar force push. Informar ao responsável o commit enviado e o resultado das verificações.
